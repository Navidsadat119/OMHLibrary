# OMH Library — کتابخانه عمرمختار هاشمی

نسخهٔ تولیدی پروژهٔ کتابخانه دیجیتال OMH، با PHP 8.3 + PostgreSQL + Docker/Render.

## ساختار نهایی رابط
- خانه
- کتابخانه
- ارسال کتاب
- مؤلفین و زندگی‌نامه‌ها
- ارتباط با ما
- دو منوی گوشه‌ای: منوی اصلی و موضوعات چندسطحی
- دری، پښتو، العربية، English
- حالت تاریک پیش‌فرض + حالت روشن با ذخیره انتخاب
- طراحی Responsive برای موبایل، تبلت و دسکتاپ

## کتابخانه
- علوم
- فنون درسی
- کتاب‌های مکتب
- علوم عصری
- کتاب‌های من
- فهرست کتاب‌ها به سبک جدولی/کاتالوگی
- صفحه‌بندی، مرتب‌سازی و جستجو
- جلد کوچک، مؤلف، جلدها، بازدید و دانلود
- کتاب‌های چندجلدی
- روابط شرح، حاشیه/تعلیقه و آثار مرتبط
- صفحه اختصاصی کتاب و مؤلف
- Featured Books با اسلایدر افقی، کنترل و swipe موبایل
- پربازدیدترین و کتاب‌های به‌روز شده
- پیشنهاد تصادفی

هیچ بخش مستقل «آخرین کتاب‌ها» و هیچ لینک مستقل «همه کتاب‌ها» در رابط عمومی وجود ندارد؛ مسیر `/books` صفحهٔ ساختار کتابخانه است و برای دیدن فهرست، کاربر یک بخش یا «کتاب‌های من» را انتخاب می‌کند.

## جستجو
جستجوی مشترک کتاب‌ها، مؤلفین و علوم با چک‌باکس، نرمال‌سازی برخی حروف عربی/فارسی و جستجو در عنوان، مؤلف، کلیدواژه و معرفی.

## ارسال کتاب
ارسال بدون حساب، PDF یا لینک خارجی، کاور، اطلاعات کتاب، وضعیت حقوق نشر، کد پیگیری و کد ویرایش. ارسال‌ها تا تأیید مدیریت عمومی نمی‌شوند.

## مدیریت
- ورود مدیر با password hashing
- نقش پایهٔ `super_admin` و `editor`
- CSRF و session سخت‌گیرانه
- بازیابی رمز با token یک‌بارمصرف و انقضای ۳۰ دقیقه‌ای از مسیر ایمیل مالک
- مدیریت کتاب، جلد، کاور، مؤلف، علوم و سلسله‌مراتب، Featured و ترتیب، منابع خارجی، سایت‌های من، بازخورد و تنظیمات
- audit log پایه
- شمارش بازدید و دانلود
- محدودیت MIME و اندازه فایل

## فایل‌ها و حقوق نشر
PDFها در PostgreSQL ذخیره نمی‌شوند؛ فایل در storage قرار می‌گیرد و دانلود از endpoint ثبت‌شده انجام می‌شود. برای آثار دارای حق نشر، فقط فایل دارای اجازه یا پیوند قانونی را میزبانی کنید.

## Render
`render.yaml` و `Dockerfile` آماده‌اند. در Render مقدارهای `APP_URL`، `ADMIN_EMAIL` و `ADMIN_PASSWORD` را تنظیم کنید. `APP_URL` باید آدرس واقعی سرویس باشد، مانند `https://omh-library.onrender.com`.

## راه‌اندازی محلی
```bash
cp .env.example .env
php database/migrate.php
php database/seed.php
php -S 127.0.0.1:8080 -t public
```

## بررسی قبل از انتشار
تمام فایل‌های PHP پروژه با `php -l` بررسی شده‌اند. اجرای کامل migration/seed و HTTP واقعی نیاز به PostgreSQL و محیط Docker/Render دارد؛ این محیط محلی فاقد Docker و PostgreSQL است، بنابراین نتیجهٔ این دو مرحله بدون ادعای ساختگی گزارش می‌شود.


## Islamic source directory
The catalog includes 20 external Islamic/Hanafi source directories as links and source metadata. OMH Library does not automatically copy third-party copyrighted PDFs; book records may point to the original source, while locally hosted files require appropriate permission.
